## Wortschatz 1.13

### 拼写也要拼对才算通过

学完一轮的拼写测试，从「测完给分」改成「拼对才通过」：

- 每个词必须**拼写正确**才算出队
- 拼错时当场显示正确答案（如「正确答案：Europa」），点「继续测试」后这个词会被**挪到队尾**，其余词测完后再回来重测，直到拼对为止
- 全部拼对后才进入结果页

顶部进度改为「已通过数 / 总数」，进度条按通过比例增长，不再是答题序号。

### 结果页

不再显示「N/总数 拼写正确」这种必然满分的口径，改为更有信息量的两行：

- **「全部拼对」** 作为完成标题
- **「X / 总数 第一次就拼对」** —— 反映真实记忆水平
- 若有重测，追加一行「共尝试 N 次」

### 实现

拼写队列独立管理：拼对出队、拼错移回队尾；`spellFirstTry` 记录首拼即对的词数，
`spellAttempts` 记录总尝试次数，用于结果页统计。

### 实测

一轮 5 词：`Frankfurt` 故意拼错 → 显示正确答案并移到队尾；
依次拼对 okay / Oh! / Viel Spaß! / Bis bald! 后 `Frankfurt` 回来，拼对后完成。
结果页显示「全部拼对 · 4 / 5 第一次就拼对」。
