# Wortschatz 1.3 · 主题、单词书、拼写测试、打卡日历

## 外观

设置里新增**主题**：跟随系统 / 浅色 / 深色，切换立即生效并记住选择。

## 单词书

设置页顶部可以选一本词书，学习与复习都只从这本书取词：

| 词书 | 词数 |
|---|---|
| A1 入门 | 1278 |
| A2 基础 | 1623 |
| B1 进阶 | 2953 |
| B2 提高 | 4474 |
| 全部词库 | 10328 |

原来的等级多选保留为「自定义学习范围」，选了书之后再微调也可以。

## 首页拆分学习与复习

今日任务卡片现在同时显示两个数字：**待复习** 和 **待学习**，
下面分别是「开始复习」和「学新词」两个入口——想只清复习、或只想推进新词，都可以单独开始。

每轮背多少个也能在设置里调（5–100）。复习优先安排到期词，不足的部分补新词。

## 拼写测试

学完一轮自动进入拼写自测：看中文释义写出德语单词。

- 首字母提示，不直接给答案
- 变音字母可以用 `ae` / `oe` / `ue` 拼，冠词、大小写不计入对错
- 判对后自动朗读正确发音，判错会显示标准答案
- 全部做完给分数与建议，按正确率给不同反馈

不想要可以在设置里关掉，关掉后学完直接回首页。

## 打卡日历

首页右上角的火苗可以点进去，是月历视图：

- 打卡的日子整格填色，今天用金色边框标出
- 可以左右切换月份看历史
- 底部汇总连续天数、累计打卡、已学词条
