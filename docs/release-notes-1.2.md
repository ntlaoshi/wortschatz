# Wortschatz 1.2 · 词库扩到一万，手势背单词

## 词库从 1616 扩到 10313

| 等级 | 词条数 |
|---|---|
| A1 | 1278 |
| A2 | 1623 |
| B1 | 2953 |
| B2 | 4474 |
| **合计** | **10313** |

这次不是靠机器翻译堆量。释义取自**中文维基词典**——由社区人工编纂，
在 174278 条德语词条中有 **99.7%** 带中文释义，这个覆盖率是之前 FreeDict
组合方案（18.4%）完全没法比的。

名词的 der/die/das 与复数形式取自**英文维基词典**的结构化数据，
没有性别的名词一律不入库——缺冠词的德语名词对学习者没有意义。

等级按德语词频表分级，只收录前 22000 名的词，避免生僻词稀释学习队列。

### 做了哪些清洗

- 剔除变位形式（`red` = reden 的命令式这类伪词条）
- 剔除古语、弃用义项
- 繁转简
- 去掉释义里的 `pl.` / `⟨中⟩` / `［阳］` 等语法噪声前缀
- 剔除错误的与格复数（`die Wundern` → 应为 `Wunder`）

## 背单词改为滑动手势

不用点「查看释义」就能直接评分，四个方向各对应一个操作：

| 手势 | 动作 |
|---|---|
| 左滑 | 认识 |
| 右滑 | 忘了 |
| 上滑 | 模糊 |
| 下滑 | 收藏 |

卡片跟手位移并随横向拖动轻微旋转，方向徽章随拖动距离淡入，
松手后飞向对应方向再切换下一张；未达阈值则弹回。

底部的「太简单」档已按你的要求移除，现在只剩忘了 / 模糊 / 认识三档，
点按钮或用手指滑都可以。

## 其他

- 音频索引改为后台加载，冷启动不再被上千个文件名的读取拖慢
- 词库外或无内置音频的词，取不到发音时会明确提示，不再是静默失败
- 版本号 1.2（versionCode 3）

## 安装

下载 `app-release.apk` 直接覆盖安装即可，已有的学习进度和生词本会保留，
新词条会在首次启动时增量导入。

## 已知限制

- 内置发音覆盖 A1–B1 词条，B2 及低频词需联网获取
- 维基来源的释义未经逐条校对，个别词条存在义项偏窄的情况，建议与权威词典交叉验证
