# Wortschatz 1.4 · 自定义单词书、已掌握标记、学习记录管理

## 单词书可以自己建了

设置页的单词书列表底部有「新建单词书」：

- 起个名字，勾选包含哪些等级（A1–B2 任意组合）
- 列表里会显示词数和包含的等级
- 自建的书右侧有编辑和删除图标，改名、改范围都行
- 内置的五本（A1/A2/B1/B2/全部）不可修改，避免误删

新建的书会自动切换为当前使用，学习与复习立刻只从这本书取词。

## 已掌握

单词卡片右上角新增「已掌握」按钮。点一下：

- 这个词立即退出本轮队列
- **此后永远不再进入复习队列**
- 也不参与拼写测试

点错了可以撤销：在学习记录页的「已掌握」列表里点撤销，词会回到复习计划。

## 学习记录可以逐个管理

设置 →「学习记录」→「管理已学习 / 已掌握」，两个标签页：

**已学习** —— 正在复习计划里的词，每行两个操作：
- ✓ 标记为已掌握
- 🗑 移除学习记录（回到未学，可重新学）

**已掌握** —— 不再复习的词，点撤销放回复习计划。

原来的「清除全部学习记录」保留在下方，仍然带二次确认。

## 数据兼容

这次给学习进度表加了「已掌握」字段，数据库版本从 1 升到 2。
**升级方式改成了增量迁移**（`ALTER TABLE` 加列），不再重建表——
你之前所有的学习进度、打卡记录、收藏都会保留。
