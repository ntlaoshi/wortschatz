# Wortschatz 1.1 · 完全离线的德语发音

## 这一版解决了什么

上一版依赖系统 TTS 朗读，而很多设备的系统「文字转语音」里**根本没有德语语音包**，
装不上就完全听不到发音。这一版把发音从系统组件里彻底剥离出来。

### 内置 1616 条德语离线音频

- 语音由微软 Edge 神经网络语音（`de-DE-KatjaNeural`）离线合成，接近真人朗读，不是机械音
- 覆盖词库中每一个单词，随 APK 一起分发
- **不需要联网、不需要装任何语音包、不需要系统 TTS 引擎**，飞行模式照样发音
- 单声道 22.05 kHz / 32 kbps 转码，单条约 7 KB，全部音频约 11 MB

### 三级发音降级

1. 内置音频 — 词库内单词，零延迟离线播放
2. 在线合成 — 词库外的新词（在线查词命中的），首次联网下载后缓存到本地，之后同样离线可播
3. 系统 TTS — 仅用于例句朗读，设备装有德语语音包时生效；没有则例句联网合成

## 其他改动

- 语速调节对内置音频同样生效（0.5x–1.3x，播放中实时变速）
- 设置页改为显示「离线发音已内置 · N 词」，不再检测系统语音包是否可用
- 新增「试听单词 / 试听句子」两个入口，便于快速验证
- 修复：从查词跳转词条详情时软键盘遮挡内容
- 全局字体改为系统默认无衬线

## 安装

下载 `app-release.apk` 直接安装。系统要求 Android 8.0（API 26）及以上。

首次启动会自动导入 1616 个词条，无需联网。
