## Wortschatz 1.23

这一版修的是**导入结果和原文对不上**，另外把常用入口从设置页搬到了首页。

### 一、导入：多了不该有的词、少了该有的词

两个现象其实是三个 bug 叠在一起。

**1. 词库里存在只差大小写的同形词，批量匹配会把两个都拉进来**

词库里有 8 组这样的词：`bitte`/`Bitte`、`leben`/`Leben`、`morgen`/`Morgen`、`arm`/`Arm`、
`wissen`/`Wissen`、`aussehen`/`Aussehen`、`vertrauen`/`Vertrauen`、`verhalten`/`Verhalten`。

原来用一条 `FOLDED_LEMMA IN (...)` 批量查，大小写被折叠掉，文本里只写了 `bitte`，
结果里却连名词 `Bitte` 一起出来——**这就是"文本里没有的词却出现了"**。

现在改成**逐词元匹配**，每个词元只取一个最贴切的词条，优先级：
① 大小写完全一致 → ② 忽略大小写 → ③ 折叠变音字母（`Gemuese`→`Gemüse`）→ ④ 匹配整条词形（`der Hund`）。

于是 `bitte` 只出 `bitte`，`Leben` 出 `das Leben`，`leben` 出 `leben`，互不串。

**2. 结果按词库顺序返回，不按文本顺序**

批量查的返回顺序是词库 rowid，跟原文毫无关系。逐行对照照片时，
排在后面的词看不到、前面冒出来的又对不上——**这就是"文本里有的词却没导入"**。

现在结果**严格按文本/照片里的先后顺序**排列，且原文写法与词库词形不同时会标注一行「原文 Gemuese」，
可以逐行核对。

**3. `bitte`、`danke`、`ja`、`nein` 被当成虚词丢掉了**

这四个是教材里的正经词汇，早前误放进停用词表，导致它们永远进不了单词书。
已从停用词里移除，停用词表现在只保留纯功能词（der/die/und/ist 等）。

**4. 同名书会被复用，旧词混进新书**

导入时如果已存在同名书，原来会直接追加进去——第二次导入后打开书，能看到上一次导入的词。
现在每次导入都新建一本，重名自动编号（`文本导入` → `文本导入 2`），完成后弹出「已导入 N 个词到《书名》」。

**5. 顺手修的：导入页没接系统返回键**

在拍照 / 文本导入页按返回会直接退出整个应用。已补上，现在返回上一页。

### 二、常用功能搬到首页

设置页确实堆得太满，导入入口要滚好几屏才摸到。现在首页「今日任务」下方新增一排快捷入口：

| 入口 | 去向 |
|---|---|
| 拍照导入 | 拍照 / 相册识别单词表 |
| 文本导入 | 粘贴词表文本 |
| 单词书 | 跳到设置页的词书选择（选书、重命名、删除、新建） |
| 学习记录 | 已学习 / 已掌握列表，可逐个标记 |

设置页相应精简：删掉拍照 / 文本导入按钮，「学习记录」卡只保留统计与清除按钮，
留下的是真正的设置项——学习等级、每轮词数、拼写测试、名词复数、外观、发音、JSON 词表导入、关于与许可。

### 实测

- 文本 `bitte Arm arm Leben leben Gemuese Strasse` → 命中 7 个，顺序与文本一致；
  `bitte`、`der Arm`、`arm`、`das Leben`、`leben` 各自独立，`das Gemüse`/`die Straße` 标注原文写法
- 拍照 14 词单词表 → 命中 15 个（含标题里的 `Kapitel`），未收录 1 个（页面标题 `Wortschatz`），
  没有再出现凭空多出的词
- 连续两次导入：旧书 `文本导入`（3 词）保留，新书 `文本导入 2`（7 词）另建，互不影响
