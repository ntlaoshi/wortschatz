# Wortschatz 1.7 · 导入词表直接生成单词书

## 导入即建书

之前的导入只是把词塞进主词库，跟内置的 10313 个词混在一起。
现在改为：

**导入一个 JSON 词表 → 自动新建一本同名单词书，词全部归到这本书下，并自动切换为当前用书。**

书名取自词表顶层的 `name` 字段：

```json
{
  "name": "Menschen A1 · 加粗词条",
  "words": [ { "w": "der Hund", "zh": "狗" } ]
}
```

没有 `name` 就用「导入词表」。

实测导入教材词表后：

- 单词书列表里出现《Menschen A1 · 加粗词条》，459 词，已自动选中
- 首页「待学习」立刻变成 459，学习与复习只从这本书取词，不会再混进词库其他内容
- 设置页出现「管理《Menschen A1 · 加粗词条》的单词」入口，可以继续加词或移出

同名书已存在时会复用，不会反复导入产生一堆同名书。

## 细节

- 同一个词根在词库里可能对应多条记录（不同词性/释义），建书时每个词根只取一条，
  书里的词数不会虚高
- 词库里本来就有的词不会重复插入，但仍会挂进新书——整份词表在书里是完整的
- 导入按钮文案改为「导入词表并新建单词书」，说明文字同步更新
