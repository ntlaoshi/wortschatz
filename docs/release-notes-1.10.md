## Wortschatz 1.10

### 复数显示方式可选

设置 → 名词复数，两个选项：

- **完整形式**（默认）：`复数 die Männer`
- **只显示词尾**：`复数 ¨-er`，与教材词汇表的写法一致

切换后立即生效，卡片、列表、详情页、拼写测试同步改变，重启后保留选择。
设置页内嵌一个实时预览（der Mann），切换选项时当场看到两种写法的差别。

### 词尾是怎么算的

不是简单截取字符串，而是按德语构词规则比对单复数：

1. 去掉冠词，把 ä/ö/ü/ß 折叠成 a/o/u/s 后求最长公共词干
2. 词干之后的部分即词尾
3. 若词干里出现了单数没有的变音字母，词尾前加 `¨`
4. 复数与单数完全同形显示「同形」，只变音（der Vater → die Väter）显示 `¨`

实例：

| 词条 | 完整形式 | 词尾形式 |
|---|---|---|
| der Mann | 复数 die Männer | 复数 ¨-er |
| das Haus | 复数 die Häuser | 复数 ¨-er |
| die Frau | 复数 die Frauen | 复数 -en |
| der Vater | 复数 die Väter | 复数 ¨ |
| das Mädchen | 复数 die Mädchen | 复数 同形 |
| das Haustier | 复数 die Haustiere | 复数 -e |
| der Bus | 复数 die Busse | 复数 -se |

单复数毫无共同前缀的不规则词（如 der Mensch / die Leute 这类数据里不会出现，
但个别外来词会有）退回完整形式，避免输出无意义的词尾。

### 覆盖范围

卡片正面、卡片背面（性与复数一起）、查词列表、收藏列表、书内单词管理、
学习记录、拼写测试判分区、词条详情页，全部跟随该设置。
