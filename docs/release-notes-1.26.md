## Wortschatz 1.26

三件事：**导入可删除/清除**、**拼写页按钮上移且键盘常驻**、**全局撤销**，外加启动动画重做。

### 一、导入支持删除与清除

拍照导入、文本导入的结果列表：

- 每行右侧一个 ✕，删掉识别错或多出来的那一条（未收录的词也能删）
- 列表顶部「清除」，一键清空全部结果（文本导入同时清空输入框）
- 删错了马上按撤销，条目会回来

### 二、拼写页：按钮上移，键盘不再收

- 「检查 / 下一题 / 继续测试 / 查看结果」移到页面右上角，「跳过这个词」在左上角；
  键盘弹起时也不用够底部
- 判定后**键盘保持展开**，输入框保留原答案，直接改错重拼即可
- 换题时自动把焦点交回输入框

### 三、全局撤销（只回退最近一步）

底部浮出提示条「已 xxx · 撤销」，6 秒内点撤销即可回退。覆盖：

| 位置 | 可撤销的操作 |
|---|---|
| 学习页 | 评「忘了/模糊/认识」、标记已掌握、下滑收藏 |
| 拼写测试 | 提交答案、跳过一个词、进入下一题 |
| 导入 | 删除单条、清除全部结果 |
| 收藏 | 加入/移出生词本 |

评分撤销会把队列、连续认识计数、复习进度一并还原，当天的复习/新学计数也会减回去，
不是只把卡片倒回去。

### 四、启动动画

- 圆形 W 标识淡入 + 弹性缩放，标题与副标题错开 140ms 上浮，底部进度稍后浮现
- 加载完成后与首页做 380ms 淡入淡出，不再「啪」地切换

### 实测

- 拼写页输入 `xyz` → 检查 → 显示正确答案与复数，键盘仍在，按钮变「继续测试」；
  点撤销 → 反馈消失、按钮回到「检查」、输入框仍是 `xyz`
- 文本导入删一条后撤销，条目回到列表
- 学习页评「认识」后撤销，卡片回到原词、进度回退
