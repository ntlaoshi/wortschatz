## Wortschatz 1.14

### 修复：翻卡后评下一张会短暂露出释义

现象：在背面评分后，下一张卡片会先露出释义，约一秒后才翻回正面。

原因有两层：

1. 评分要写数据库，`revealed` 复位写在协程里，磁盘写完才生效；而卡片在评分瞬间就被弹回原位，
   这段时间里旧卡的背面一直停在屏幕中央
2. 翻面动画只按 `revealed` 做补间，换词时旧状态会用**新单词**重绘背面，
   即使复位及时，动画期间也会看到新词的释义

对应修复：

- `rate()` / `masterCurrent()` 里把 `revealed = false` 提到协程之前，点击瞬间就合上背面
- 翻面动画的状态改为 `(词条 id, revealed)`：换词时用无动画直接切换，只有同一张卡翻面才做淡入缩放

实测：背面评分后 0.5 秒截图，新卡已是正面（仅单词 + 标签 + 「轻触卡片查看释义」），无中文释义。

### 新增：拼写时的变音字母按键

问题：多数手机键盘没有 ä ö ü ß，遇到带变音字母的词根本打不出来。

现在拼写输入框下方提供四个可点按键 **ä ö ü ß**，点一下追加到输入内容；
下方另有一行说明「打不出变音字母时，也可以写 ae / oe / ue / ss」。

判定规则不变：ä=ae、ö=oe、ü=ue、ß=ss 双向等价，冠词、大小写、句末标点都不计入差异。
即使用户自己敲键盘写 `ue`，或点按钮输入 `ü`，都能判对。
