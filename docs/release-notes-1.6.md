# Wortschatz 1.6 · 教材词单导入 + 格式规范

## 新增：教材加粗词条词单

`docs/wordbooks/menschen-a1-bold.json` —— 从教材《Menschen》A1 词汇表里整理出的
**463 条印刷加粗词条**，全部标为 A1 等级、标签「教材」。

直接导入即可：设置 → 词库 → 导入自定义词表（JSON）。

实测导入后新增 220 条——另外 243 条词库里本来就有（`der Mann`、`die Frau`、`kommen`
这类），按去重规则被跳过了，不会产生重复条目。

## 新增：单词本格式规范

`docs/wordbook-format.md` 写清了 JSON 结构、字段含义、词性代码表、去重规则，
以及一份从 Excel 等外部数据转换的最小示例脚本。

最小可用格式只要两个字段：

```json
{ "words": [ { "w": "der Hund", "zh": "狗" } ] }
```

## 修复：导入去重不彻底

之前按「词形 + 词性 + 释义」三者全等才判定重复，导致同一个词只要释义措辞不同
就会入库两条。现在改为**按词根比对**（`l` 或去冠词的 `w`，忽略大小写），
已存在的词直接跳过。

顺带修了一个边界情况：词库里的 `Auf Wiedersehen` 词根不带感叹号，教材写成
`Auf Wiedersehen!`，规范化不一致会被当成两个词。现在生成词单时统一去掉首尾标点。
