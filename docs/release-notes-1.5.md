# Wortschatz 1.5 · 单词书改成自选词，搜索框显示修复

## 单词书：自己挑词，不再选等级

上一版新建单词书要勾 A1/A2 这些等级，等于是把内置书的分类逻辑套到了自建书上。
现在改成：

- **新建时只填名字**，建出来是一本空书
- 点「管理《书名》的单词」进去，搜索单词、点 + 加进书里
- 书里的词点右侧 ✕ 移出
- 学习与复习只从当前这本书取词

内置的五本（A1 入门 / A2 基础 / B1 进阶 / B2 提高 / 全部词库）保持不变，仍然按等级划分。

实测：建了一本只装了 `das Haus` 和 `der Hauser` 的书，开始学习时队列就是 0/2，
不会混进词库里的其他一万个词。

### 说明

上一版按等级建过的自建书，升级后会变成空书（等级条件不再适用），
名称和书本身都还在，重新往里加词即可。

## 搜索框显示修复

之前的占位文字「输入德语单词或中文，如 Hund」太长，在小屏上折成两行，
把整个输入框撑高到两倍。现在：

- 占位文字缩短为「搜德语或中文」，强制单行、超出省略
- 输入框恢复标准高度
- 书详情页的搜索框同样处理

## 数据兼容

数据库版本 2 → 3，新增 `book_words` 表存放书与词的关联，
同样是增量迁移，学习进度、打卡、收藏均不受影响。
